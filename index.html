👉 Để kết nối được Bluetooth, bạn chỉ cần:
• Mở bằng VS Code: Chuột phải index.html chọn "Open with Live Server" (chạy qua http://127.0.0.1:5500).
• Hoặc mở Terminal gõ: python -m http.server 8000 rồi vào http://localhost:8000.
• Hoặc đưa file lên GitHub Pages / Hosting (HTTPS).
